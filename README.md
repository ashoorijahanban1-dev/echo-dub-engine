# 🎓 پایپ‌لاین دوبله فارسی و انتشار خودکار دوره‌های RPIM TV (نسخه v2)

این پروژه یک پایپ‌لاین خودکار، ماژولار و تاب‌آور برای کشف، انتقال امن، استخراج، دوبله صوتی فارسی با همگام‌سازی خط زمانی، ارزیابی خودکار کیفیت (Automated QC Gate)، ذخیره‌سازی ابری در شبکه تلگرام با پروتکل استریمینگ ۲۴/۷ (RFC 7233 Range) و انتشار ساختاریافته در سایت رسمی [rpim.ir](https://rpim.ir) است.

---

## 🚀 راهنمای راه‌اندازی سریع در محیط توسعه و تست

برای نصب پیش‌نیازها و راه‌اندازی مستقل پایپ‌لاین:

`ash
# همگام‌سازی و نصب کلیه وابستگی‌های اصلی و اختیاری (تست و پستگرس)
uv sync --all-extras

# اجرای کلیه آزمون‌های خودکار
uv run pytest -v
`

## 🏗️ ساختار ماژول‌ها و فایل‌های پروژه

- server.py: سرویس مرکزی FastAPI با اندپوینت‌های پردازش غیرهمگام (202 Accepted)، احراز هویت داخلی، گیت‌وی استریم تلگرام و ریکاوری.
- elay_server.py: سرور پروکسی امن در دیتاسنتر ایران با محافظت سخت‌گیرانه در برابر SSRF و فوروارد دامنه و توکن.
- config.py: مدیریت متمرکز تنظیمات محیطی، آستانه‌های حافظه دیسک، قفل‌ها و مقادیر پیش‌فرض.
- database.py: لایه ذخیره‌سازی داده دوگانه (Discovery DB و Processing DB) با سازگاری کامل لایه دیتابیس (Dialect-Aware) برای SQLite و PostgreSQL.
- workers/job_runner.py: اجرای ترتیبی و توزیع‌شده جاب‌های ۶گانه پایپ‌لاین با قفل توزیع‌شده (Fencing Token) و مکانیزم Retry/Dead-Letter.
- dapters/: آداپتورهای تخصصی تعامل با تلگرام (	elegram.py)، استخراج امن آرشیو (extractor.py)، ساخت دوبله و کنترل کیفیت (dubber.py)، تاکسونومی هوشمند (	axonomy.py)، انتشار در وب‌سایت (publisher.py) و انتقال رزوم‌پذیر (	ransfer.py).
- workflows/: شش گردش کار استاندارد n8n (WF01 تا WF06) با اعتبارسنجی اتصالات و چرخه‌های Polling تطبیقی.
- 	ests/: مجموعه کامل آزمون‌های واحد، شبیه‌سازها (Fake HTTP Servers)، ادغام دیتابیس و پایپ‌لاین ترتیبی.
- RUNBOOK.md: راهنمای جامع عملیاتی، استقرار کانتینری با Docker Compose و عیب‌یابی سرورها.

## 🔒 امنیت و متغیرهای محیطی

یک فایل نمونه [.env.example](.env.example) در پروژه قرار داده شده است. قبل از استقرار، فایل .env را ایجاد کرده و توکن‌ها و کلیدهای محرمانه با حداقل ۳۲ کاراکتر تصادفی را مقداردهی نمایید. هرگز فایل حاوی مقادیر واقعی را در گیت یا آرشیوهای توزیع‌شده قرار ندهید.
